# Grupo ISAMIG — Site institucional

Site estático para GitHub Pages. Publique `index.html` e a pasta `dados/` na raiz do repositório `washingtonOF.github.io`.

## Atividade do GitHub

O painel consulta até 100 commits recentes por repositório configurado no código. A API pública do GitHub tem limites e repositórios indisponíveis não são contabilizados. Dias ativos correspondem a dias com commits, não dias necessariamente trabalhados. O número de repositórios exibido representa apenas os repositórios configurados que responderam à consulta, não o total da conta.

## Horas reais

Edite `dados/horas.json`, por exemplo:

```json
{"registros":[{"data":"2026-11-12","projeto":"Miguelzãoo","horas":2.5}]}
```

Não inclua tokens ou senhas no site.
